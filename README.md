# proyecto-sprint7
# proyecto sprint 7
# En este proyecto, se hizo un historiograma  y un grafico de dispersion para el conjunto de datos de anuncios de venta de coches. Para facilidad del usuario, se genero un boton de acceso para el historiograma y el grafico de dispersion. Posteriromente se subio a Render atraves de Github.

## 🚀 Dashboard en Streamlit

## 📂 Archivos incluidos
- app.py — Código principal del dashboard  
- requirements.txt — Dependencias necesarias  

## 🧠 Propósito del proyecto
El objetivo de este proyecto es realizar un análisis exploratorio de datos de un conjunto de datos de anuncios de coches.
